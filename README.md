# SHISHKA

Мобильный веб-прототип интерфейса выбора предпочтительного региона для Mobile Legends: Bang Bang.

## Что есть сейчас

- Адаптивный интерфейс на русском языке.
- Выбор континента и страны.
- Список демонстрационных регионов с явно помеченными примерными значениями пинга.
- Выбор предпочтительного региона в текущей сессии.
- Локальная диагностика, настройки интерфейса и FAQ.
- Учитывается системная настройка уменьшения анимации.

## Важно: это пока не VPN

Эта веб-страница **не** создаёт VPN-профиль, не меняет IP-адрес или маршрут трафика, не фильтрует соединения и не может гарантировать регион игрового матчмейкинга. Все значения пинга — демонстрационные, а не измерения с устройства. Не следует считать выбор региона подключением к игровому серверу.

## Запуск

Откройте `index.html` в современном браузере или включите GitHub Pages в настройках репозитория, выбрав ветку `main` и корневую папку `/`.

Проект использует обычные HTML, CSS и JavaScript, поэтому установка зависимостей и сборка не требуются.

## Следующий этап: Android

Для нативного Android-клиента потребуется отдельный проект, использующий Android `VpnService`, явное согласие пользователя, корректное управление жизненным циклом VPN, прозрачные настройки маршрутизации и проверяемые тесты на реальных устройствах. Сам факт использования `VpnService` не гарантирует управление подбором серверов MLBB. Сначала необходимо технически проверить доступные сетевые механизмы и правила игры. Не заявляется отсутствие риска блокировки.

Перед публикацией Android-приложения необходимо провести аудит безопасности и конфиденциальности, не собирать лишние данные и не отправлять игровой трафик на сторонние серверы без ясного согласия пользователя.

## Структура

- `index.html` — текущий веб-прототип.
- `README.md` — описание, запуск и ограничения.
- `.gitignore` — исключения для локальных и сборочных файлов.
